# Dashboard recording

**Feature.** The dashboard presents the supplied Corvette, Challenger and 2012 Corolla with illustrative photos and per-vehicle profiles.

**Sequence.** The cursor hovers across the three cards, scrolls down, opens the Challenger, inspects its edit form, returns to the garage, and opens the add-vehicle form.

**Checks.** Three starter cards render, the Challenger profile opens, the edit form retains its value, and add/edit work in a separate mobile browser test. Viewport is 1920×1080 for the recording.

**Source.** [Dashboard PR #1](https://github.com/pilercodes/virtual-garage/pull/1), dashboard commit `808482f`, and [maintenance/recording PR #3](https://github.com/pilercodes/virtual-garage/pull/3). The recording workflow uses a GitHub Actions checkout and an isolated local database. No hosted Sites release has been verified.

**Optional motion graphic.** Use a four-second charcoal title card with three thin orange lines sweeping past stylized vehicle silhouettes. Track the camera laterally with a slight push-in, then match-cut the silhouettes to the three dashboard cards. Place it immediately before the dashboard clip in the build reveal.
