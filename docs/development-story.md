# Development story

- The repository was reachable before it was writable. Attaching the repo to the cloud environment fixed the new-branch push.
- The first dashboard pairs an orange-accented automotive design with the exact starter vehicle details, including the 2012 Corolla. The images are illustrative.
- The development preview exercises actual SQL using SQLite, while production is designed for account-scoped Sites D1 storage.
- Independent review caught stale illustrative images after editing and a dead-end loading error. The dashboard now matches images to their original details and offers a retry action.
- The maintenance log uses integer cents and tests leap days and account isolation. No example records ship with the application.
