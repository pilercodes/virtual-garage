# Virtual Garage

Use Node 24. Run `npm run build`, `npm test`, and the relevant browser flow before marking a feature ready. Run `npm run dev` for a local demo with synthetic identity and SQLite.

Work on feature branches. Open pull requests and preserve commit history. Require passing checks and a separate reviewer before merging. Deploy only approved `main` commits through the private Sites workflow. Keep credentials, real vehicle records, and videos out of Git.

The starter vehicles are the 2003 Chevrolet Corvette Z06 (Silver), 2009 Dodge Challenger SRT (Hemi Orange), and 2012 Toyota Corolla (color unspecified). Never fill in unknown real maintenance, expenses, mileage, or vehicle details.
